# Оценка качества ML-моделей компьютерного зрения (командный проект) 

## О проекте
Командный исследовательский проект по разработке веб-сервиса для врачей
**Цель:** сравнить несколько архитектур нейронных сетей для задачи сегментации аорты на медицинских изображениях и выбрать лучшую модель для внедрения в веб-интерфейс

**Моя роль в команде:** независимое тестирование моделей, расчет метрик качества и участие в выборе финальной архитектуры

## Инструменты
*   **Язык:** Python
*   **Библиотеки:** PyTorch, NumPy, scikit-learn
*   **Среда:** Jupyter Notebook

## Что я тестировала

### 1. Модели для сегментации (Deeplabv3+ и Unet)
*   **Архитектуры:** Deeplabv3+ с энкодером ConvNeXt, Unet с энкодером ConvNeXt
*   **Задача:** Оценить качество сегментации аорты на тестовой выборке
*   **Метрики:** IoU (Intersection over Union), Dice coefficient

### 2. Модель Segformer (геометрические параметры)
*   **Архитектура:** Segformer
*   **Задача:** Оценить точность измерения геометрических параметров аорты (максимальный и относительный диаметр среза)
*   **Метрики:** MAE (Mean Absolute Error) для максимального и относительного диаметра среза аорты

## Результаты проекта
Все результаты тестирования (мои и коллег) были сведены в единую сравнительную таблицу 
*   В таблицу вошли метрики для всех протестированных архитектур
*   На основе сравнительного анализа команда выбрала модель-победителя, которая показала наименьшую ошибку
*   Выбранная модель была внедрена коллегами в веб-сервис для врачей
